# Moch. Agil Sugiarto Portfolio

Website portofolio pribadi modern, profesional, responsif, dan ringan untuk melamar posisi Fullstack Developer Intern.

## Tech Stack

- React.js
- Vite
- Tailwind CSS
- JavaScript

## Cara Menjalankan

```bash
npm install
npm run dev
```

## Build Production

```bash
npm run build
npm run preview
```
